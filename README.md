# Personal Portfolio Website

A modern and responsive animated portfolio website built using Next.js, TypeScript, and Tailwind CSS. This project showcases my skills, projects, experience, and contact information with a clean UI and smooth animation and user experience.

---

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS v4
- Lenis Smooth Scroll
- React Icons
- clsx
- tailwind-merge

---

## Features

- Fully Responsive Design
- Smooth Scrolling with Lenis
- Reusable UI Components
- Modern Mobile Navigation
- Download CV Functionality
- Optimized Performance
- Clean and Scalable Code Structure

---

```bash
git clone https://github.com/palakbanik/my-portfolio-website.git
```

Go to the project directory:

```bash
cd personal-portfolio-website
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
